# Video Files

Place your promotional video files here:

1. `ankit-academy-ad.mp4` - Main promotional video (MP4 format)
2. `ankit-academy-ad.webm` - WebM format for better browser support
3. `ankit-academy-ad.ogg` - OGG format for additional browser support
4. `video-thumbnail.jpg` - Thumbnail image for video preview

## Supported Video Formats:
- MP4 (H.264 codec) - Best compatibility
- WebM (VP8/VP9 codec) - Modern browsers
- OGG (Theora codec) - Firefox/Opera support

## Recommended Video Specs:
- Resolution: 1920x1080 (Full HD) or 1280x720 (HD)
- Duration: 30-60 seconds
- File size: Under 10MB for fast loading
